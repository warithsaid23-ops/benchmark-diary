Operations manager guide

Use confirmed records from the CEO dashboard and Sheet to follow daily accountability.

  1. Check that each active project has a diary record for the correct diary date.
  2. Follow up on delayed or at-risk programme status, hours lost and safety flags.
  3. Review attendance, tasks for tomorrow, materials requested and incident details.
  4. Ask an engineer to retry the same report only when no row was saved or the report is still pending.
  5. Do not ask for a second submission when the original row exists; investigate the recorded email status instead.

Photos remain separate from the Sheet workflow. Confirm receipt of site photos through the agreed project channel.
