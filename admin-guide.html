Admin guide

Use the Admin panel to see the configured Sheet and Apps Script links. The page does not claim that delivery is verified.

  1. Back up the Sheet and Apps Script project before a backend change.
  2. Deploy the backend source from the private backend source in the bound Sheet project.
  3. Set the Sheet ID and tab gid in Script properties.
  4. Preserve columns AE–AG: Submission ID, Email Status and Payload Hash.
  5. Update the existing Web app deployment, keeping the current /exec URL whenever possible.
  6. Run the controlled test and check the new row before telling engineers to use the release.

Retries use the permanent report ID and do not resend email for a saved row. Inspect logs and recipient delivery when the Sheet row reports a mail warning.
